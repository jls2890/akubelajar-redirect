# akubelajar.id apex redirect

Tiny GitHub Pages site whose only job is to send visitors of the bare domain `akubelajar.id` to `https://www.akubelajar.id`, which is hosted on Cloudflare Pages. It exists because the DNS provider (IDwebhost) only supports A records at the root, and GitHub Pages offers fixed IPs for that.

DNS at IDwebhost: four A records for `@` pointing to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153.
